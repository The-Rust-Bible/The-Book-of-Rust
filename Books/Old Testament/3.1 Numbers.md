# Book of Numbers

*Rust topic: Collections — Vec, String, HashMap, HashSet*

## Chapter 1: Vectors

1 A `Vec<T>` is a growable array stored on the heap. Unlike arrays, its size can change at runtime:
   ```rust
   let mut v: Vec<i32> = Vec::new();
   v.push(1);
   v.push(2);
   v.push(3);
   ```

2 The `vec!` macro creates a vector with initial values:
   ```rust
   let v = vec![1, 2, 3];
   ```

3 Create a vector with repeated values using `vec![value; count]`:
   ```rust
   let v = vec![0; 5]; // [0, 0, 0, 0, 0]
   ```

4 Access elements by index with `[]` (panics on out-of-bounds) or `.get()` (returns `Option`):
   ```rust
   let v = vec![1, 2, 3];
   let third: &i32 = &v[2];       // 3
   let maybe: Option<&i32> = v.get(10); // None
   ```

5 Access elements mutably by index:
   ```rust
   let mut v = vec![1, 2, 3];
   v[0] = 10; // v is now [10, 2, 3]
   ```

6 Iterate over a vector immutably:
   ```rust
   let v = vec![1, 2, 3];
   for i in &v {
       println!("{i}");
   }
   ```

7 Iterate mutably to modify each element:
   ```rust
   let mut v = vec![1, 2, 3];
   for i in &mut v {
       *i += 1;
   } // v is now [2, 3, 4]
   ```

8 Iterate by value (consumes the vector):
   ```rust
   let v = vec![1, 2, 3];
   for i in v {
       println!("{i}");
   } // v is no longer usable here
   ```

9 Enumerate gives both index and value:
   ```rust
   let v = vec![10, 20, 30];
   for (i, val) in v.iter().enumerate() {
       println!("{i}: {val}");
   }
   ```

10 Vectors store all elements contiguously in memory. Adding elements may trigger reallocation if capacity is exceeded.

11 The `len()` method returns the number of elements. The `capacity()` method returns the allocated capacity.

12 Use `Vec::with_capacity(n)` to pre-allocate for efficiency when you know roughly how many elements you will add.

13 `pop()` removes and returns the last element, or `None` if empty:
   ```rust
   let mut v = vec![1, 2, 3];
   let last = v.pop(); // Some(3), v is now [1, 2]
   ```

14 `remove(index)` removes and returns the element at `index`, shifting all subsequent elements left.

15 `insert(index, value)` inserts at `index`, shifting subsequent elements right.

16 `truncate(len)` shortens the vector to `len` elements, dropping the rest.

17 `drain(range)` removes a range of elements and returns an iterator over them:
   ```rust
   let mut v = vec![1, 2, 3, 4, 5];
   let removed: Vec<i32> = v.drain(1..3).collect(); // [2, 3]
   // v is now [1, 4, 5]
   ```

18 `retain(predicate)` keeps only elements matching the predicate:
   ```rust
   let mut v = vec![1, 2, 3, 4, 5];
   v.retain(|&x| x % 2 == 0); // [2, 4]
   ```

19 `dedup()` removes consecutive duplicate elements:
   ```rust
   let mut v = vec![1, 1, 2, 3, 3, 3];
   v.dedup(); // [1, 2, 3]
   ```

20 Concatenate vectors with `.extend()`:
   ```rust
   let mut v1 = vec![1, 2, 3];
   let v2 = vec![4, 5, 6];
   v1.extend(v2); // v1 is now [1, 2, 3, 4, 5, 6]
   ```

## Chapter 2: Strings

1 Rust has two string types: `String` (owned, growable, heap-allocated) and `&str` (borrowed, immutable, stack-stored or in the binary).

2 Create a `String` from a string literal:
   ```rust
   let mut s = String::from("Hello");
   ```

3 Or use `.to_string()` on a `&str`:
   ```rust
   let s = "Hello".to_string();
   ```

4 Or use `String::new()` to create an empty string:
   ```rust
   let mut s = String::new();
   ```

5 `push_str` appends a string slice:
   ```rust
   let mut s = String::from("Hello");
   s.push_str(", Rust!");
   ```

6 `push` appends a single character:
   ```rust
   let mut s = String::from("Hello");
   s.push('!');
   ```

7 Concatenate with `+`:
   ```rust
   let s1 = String::from("Hello, ");
   let s2 = String::from("Rust!");
   let s3 = s1 + &s2; // s1 is moved, s2 is borrowed
   ```

8 The `+` operator uses the `Add` trait. It takes ownership of `s1` and borrows `s2`.

9 Use `format!` to create formatted strings without taking ownership:
   ```rust
   let name = "Rust";
   let version = 1;
   let s = format!("{name} {version}");
   ```

10 `format!` returns a `String`. It does not take ownership of its arguments — it uses references internally.

11 Strings are UTF-8 encoded. You cannot index into a `String` by byte position to get a character because UTF-8 characters can span multiple bytes.

12 Slicing strings requires valid UTF-8 boundaries. Slicing at an invalid boundary panics:
   ```rust
   let s = String::from("hello");
   let hello = &s[0..5]; // "hello"
   ```

13 Iterate over characters with `.chars()`:
   ```rust
   let s = String::from("Rust");
   for c in s.chars() {
       println!("{c}");
   }
   ```

14 Iterate over bytes with `.bytes()`:
   ```rust
   let s = String::from("ABC");
   for b in s.bytes() {
       println!("{b}");
   }
   ```

15 Get a substring as a `&str` slice with `&s[start..end]`.

16 `replace` returns a new `String` with matches replaced:
   ```rust
   let s = String::from("hello world");
   let replaced = s.replace("world", "Rust"); // "hello Rust"
   ```

17 `to_uppercase` and `to_lowercase` return new strings:
   ```rust
   let s = String::from("Hello");
   assert_eq!(s.to_uppercase(), "HELLO");
   ```

18 `trim` removes whitespace from both ends:
   ```rust
   let s = String::from("  hello  ");
   assert_eq!(s.trim(), "hello");
   ```

19 `split` returns an iterator over substrings:
   ```rust
   let s = String::from("a,b,c");
   let parts: Vec<&str> = s.split(',').collect(); // ["a", "b", "c"]
   ```

20 `lines` splits on newlines:
   ```rust
   let s = String::from("line1\nline2\nline3");
   for line in s.lines() {
       println!("{line}");
   }
   ```

21 `String` and `&str` are different types. Functions that accept `&str` can take both `&String` (via deref coercion) and string literals.

22 Prefer `&str` for function parameters. Use `String` only when you need ownership or mutation.

## Chapter 3: HashMaps and HashSets

1 A `HashMap<K, V>` stores key-value pairs. Keys are unique. Values can be duplicated.

2 Create a new `HashMap`:
   ```rust
   use std::collections::HashMap;

   let mut scores = HashMap::new();
   ```

3 Insert key-value pairs:
   ```rust
   scores.insert(String::from("Alice"), 100);
   scores.insert(String::from("Bob"), 85);
   ```

4 Retrieve a value by key with `.get()`:
   ```rust
   let score = scores.get("Alice"); // Some(&100)
   ```

5 `.get()` returns `Option<&V>`. Use `.copied()` to get an owned value for `Copy` types:
   ```rust
   let score = scores.get("Alice").copied(); // Some(100)
   ```

6 Iterate over key-value pairs:
   ```rust
   for (key, value) in &scores {
       println!("{key}: {value}");
   }
   ```

7 Iterate over keys only:
   ```rust
   for key in scores.keys() {
       println!("{key}");
   }
   ```

8 Iterate over values only:
   ```rust
   for value in scores.values() {
       println!("{value}");
   }
   ```

9 Update a value by inserting with the same key:
   ```rust
   scores.insert(String::from("Alice"), 110); // replaces the old value
   ```

10 The `.entry()` API is the idiomatic way to insert or update:
   ```rust
   scores.entry(String::from("Carol")).or_insert(90);
   ```

11 `or_insert` inserts a value only if the key does not exist:
   ```rust
   let count = scores.entry(String::from("Alice")).or_insert(0);
   *count += 10;
   ```

12 `and_modify` modifies an existing value:
   ```rust
   scores.entry(String::from("Alice"))
       .and_modify(|e| *e += 10)
       .or_insert(0);
   ```

13 `remove` removes a key and returns its value:
   ```rust
   let removed = scores.remove("Bob"); // Some(85)
   ```

14 `contains_key` checks if a key exists:
   ```rust
   if scores.contains_key("Alice") {
       println!("Alice has a score");
   }
   ```

15 `len()` returns the number of entries. `is_empty()` checks if the map is empty.

16 `HashSet<T>` is a set of unique values. It is implemented using a `HashMap<T, ()>` internally:
   ```rust
   use std::collections::HashSet;

   let mut set = HashSet::new();
   set.insert(1);
   set.insert(2);
   set.insert(2); // no effect — 2 is already in the set
   ```

17 `HashSet` operations:
   ```rust
   let mut a = HashSet::from([1, 2, 3]);
   let b = HashSet::from([2, 3, 4]);

   let union: HashSet<_> = a.union(&b).collect();       // {1, 2, 3, 4}
   let intersection: HashSet<_> = a.intersection(&b).collect(); // {2, 3}
   let difference: HashSet<_> = a.difference(&b).collect();     // {1}
   ```

18 `HashMap` requires keys to implement `Eq` and `Hash` traits. Most standard types do. For custom keys, derive these traits:
   ```rust
   #[derive(Hash, Eq, PartialEq)]
   struct UserId(u64);
   ```

19 `HashMap` does not preserve insertion order. If you need ordered iteration, use `BTreeMap` (sorted by key) or `IndexMap` from the `indexmap` crate.

20 The default hasher is `RandomState`, which uses a random seed per `HashMap` instance to prevent hash flooding attacks.

## Chapter 4: Choosing the Right Collection

1 Use `Vec<T>` for an ordered list of elements. Fast indexing, iteration, and append. Slow insert/remove at arbitrary positions.

2 Use `VecDeque<T>` for a double-ended queue. Fast push/pop at both ends. Use when you need a queue or a ring buffer.

3 Use `LinkedList<T>` for a doubly-linked list. Rarely the best choice — `Vec` or `VecDeque` are faster in practice due to cache locality. Use only when you need stable references to elements across insertions.

4 Use `HashMap<K, V>` for key-value lookup. O(1) average lookup, insert, remove. No ordering.

5 Use `BTreeMap<K, V>` for sorted key-value storage. O(log n) operations. Keys are kept sorted. Use when you need ordered iteration or range queries.

6 Use `HashSet<T>` for unique value membership testing. O(1) average insert, lookup, remove. No ordering.

7 Use `BTreeSet<T>` for sorted unique values. O(log n) operations. Use when you need ordered iteration.

8 Use `BinaryHeap<T>` for a priority queue. The largest element is always at the top. Use for scheduling, event simulation, or Dijkstra's algorithm.

9 Use `Vec<T>` as the default. Most problems are solved with a vector. Only reach for other collections when you have a specific need.

10 For small collections that fit on the stack, consider `arrayvec::ArrayVec<T, N>` for no-allocation vectors.

11 For small maps, consider `smallvec` or a linear search over a `Vec<(K, V)>` — sometimes faster than `HashMap` for small sizes.

12 When in doubt, start with `Vec` and `HashMap`. Profile and optimize later. Premature optimization is the root of all evil.
