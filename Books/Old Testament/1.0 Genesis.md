# Book of Genesis

*Rust topic: Variables, Types, Mutability, and Functions*

## Chapter 1: In the Beginning Was the Let Binding

Install the Rust toolchain with `rustup` and verify:
   ```bash
   rustc --version
   cargo --version
   ```

Every Rust program begins with a function named `main`:
   ```rust
   fn main() {
       println!("Hello, world!");
   }
   ```

The `fn` keyword declares a function. `main` is the entry point the runtime calls first.

The `println!` macro prints to standard output. The `!` marks it as a macro, not a function.

Declare a variable with the `let` keyword:
   ```rust
   let x = 5;
   ```

By default, all `let` bindings are immutable. Reassigning causes a compile error:
   ```rust
   let x = 5;
   x = 6; // error: cannot assign twice to immutable variable
   ```

To allow reassignment, declare the binding mutable with `mut`:
   ```rust
   let mut y = 10;
   y = 20; // allowed
   y = y + 1;
   ```

Rust infers types from the value assigned. When inference is ambiguous or you want to be explicit, annotate the type:
   ```rust
   let z: i32 = 42;
   let name: &str = "Rust";
   ```

Shadowing lets you reuse a variable name with a new value and a different type. The old binding is obscured:
   ```rust
   let spaces = "   ";       // &str
   let spaces = spaces.len(); // usize
   ```

Shadowing is distinct from `mut`: shadowing creates a new binding, while `mut` changes the value of one binding.

Constants are declared with `const`. They must be annotated, evaluated at compile time, and are immutable:
   ```rust
   const MAX_POINTS: u32 = 100_000;
   ```

Constants may live in any scope, including module level, and are inlined at each use site.

The underscore `_` can be used as a numeric separator for readability:
   ```rust
   let million = 1_000_000;
   ```

Rust is statically typed. The compiler catches type mismatches before the program runs.

## Chapter 2: The Types of All Things

Integer types come in signed and unsigned families: `i8`, `i16`, `i32`, `i64`, `i128`, `isize`.

Unsigned integer types: `u8`, `u16`, `u32`, `u64`, `u128`, `usize`. These cannot hold negative values.

The default integer type is `i32`. Choose `u32` for non-negative values, `usize` for indexing and sizes.

The `isize` and `usize` types match the pointer width of the target platform â€” 32 bits on 32-bit systems, 64 bits on 64-bit.

Integer overflow panics in debug mode and wraps in release mode by default. Use `wrapping_add`, `wrapping_sub`, or `checked_add` for explicit behavior:
   ```rust
   let max = u8::MAX;
   let wrapped = max.wrapping_add(1); // 0
   let checked = max.checked_add(1);  // None
   ```

Floating-point types are `f32` and `f64`. The default is `f64`, which has more precision:
   ```rust
   let pi: f32 = 3.14159;
   let e: f64 = 2.718281828459045;
   ```

Floating-point arithmetic follows IEEE 754. Be aware that `0.1 + 0.2 != 0.3` due to representation limits.

The boolean type is `bool` with two values: `true` and `false`.
   ```rust
   let is_active: bool = true;
   let is_deleted = false;
   ```

The character type `char` represents a single Unicode scalar value. It is four bytes in size:
   ```rust
   let letter = 'a';
   let heart = 'â¤';
   let emoji = 'ðŸ¦€';
   ```

`char` is not a string. A string is a sequence of characters (`String` or `&str`), while `char` is a single one.

Compound types group multiple values. Tuples have a fixed length and can hold different types:
   ```rust
   let person: (&str, i32, f64) = ("Alice", 30, 1.65);
   ```

Access tuple elements by index:
   ```rust
   let name = person.0;
   let age = person.1;
   ```

Destructure tuples with pattern matching:
   ```rust
   let (name, age, height) = person;
   ```

The unit type `()` is the empty tuple. It represents "no meaningful value" and is the default return type of functions.

Arrays have a fixed length known at compile time. All elements share the same type:
   ```rust
   let numbers: [i32; 5] = [1, 2, 3, 4, 5];
   let zeros = [0; 3]; // [0, 0, 0]
   ```

Access array elements by index, starting at 0:
   ```rust
   let first = numbers[0]; // 1
   ```

Out-of-bounds indexing panics at runtime. For safe access that returns `Option`, use `.get()`:
   ```rust
   let maybe = numbers.get(10); // None
   ```

Arrays are stored on the stack. For growable collections, use `Vec<T>` instead.

The unit type, tuples, arrays, and scalar types are all known as "primitive" or "built-in" types, but the line is blurry â€” everything is defined in the standard library except the language builtins.

## Chapter 3: Functions and Their Calling

Functions are declared with `fn`, followed by a name, parameters in parentheses, and an optional return type:
   ```rust
   fn add(a: i32, b: i32) -> i32 {
       a + b
   }
   ```

Parameters must have explicit types. Rust does not infer parameter types.

The return type follows `->`. If omitted, the function returns the unit type `()`:
   ```rust
   fn greet(name: &str) {
       println!("Hello, {name}!");
   }
   ```

Function bodies are blocks of statements. The final expression (without a semicolon) is the return value:
   ```rust
   fn square(x: i32) -> i32 {
       x * x // no semicolon â€” this is the return value
   }
   ```

Statements end with semicolons and do not produce values. Expressions do not end with semicolons and evaluate to a value:
   ```rust
   let y = {
       let x = 3;
       x + 1 // expression â€” block evaluates to 4
   }; // y is 4
   ```

Use the `return` keyword for early returns:
   ```rust
   fn is_positive(x: i32) -> bool {
       if x <= 0 {
           return false;
       }
       true
   }
   ```

`return` can also be used in the final position, but it is idiomatic to omit it:
   ```rust
   fn double(x: i32) -> i32 {
       return x * 2; // works, but `x * 2` is more idiomatic
   }
   ```

Functions can be used as values. The type `fn(i32, i32) -> i32` is a function pointer:
   ```rust
   let operation: fn(i32, i32) -> i32 = add;
   let result = operation(3, 4); // 7
   ```

Use `_` in a parameter list to indicate an unused parameter without a name:
   ```rust
   fn ignore(_unused: i32) {
       println!("Called");
   }
   ```

Rust convention uses `snake_case` for function names and `camelCase` for variables inside function bodies (though `snake_case` is the standard for variables too â€” Rust uses `snake_case` consistently).

The `main` function can return a `Result` to propagate errors to the runtime:
   ```rust
   fn main() -> Result<(), Box<dyn std::error::Error>> {
       let contents = std::fs::read_to_string("hello.txt")?;
       println!("{contents}");
       Ok(())
   }
   ```

## Chapter 4: Comments and Program Structure

Single-line comments begin with `//`. Everything after on that line is ignored:
   ```rust
   // This is a comment
   let x = 5; // inline comment
   ```

Block comments span multiple lines, delimited by `/*` and `*/`:
   ```rust
   /*
    * This is a block comment.
    * It can span multiple lines.
    */
   ```

Doc comments use `///` for items and `//!` for module-level documentation. They are rendered by `cargo doc`:
   ```rust
   /// Adds two integers.
   ///
   /// # Examples
   ///
   /// ```
   /// assert_eq!(add(2, 3), 5);
   /// ```
   fn add(a: i32, b: i32) -> i32 {
       a + b
   }
   ```

A Rust crate is a package of code. It is either a binary (executable) or a library.

The crate root for a binary is `src/main.rs`. For a library, it is `src/lib.rs`.

Modules organize code into namespaces. Declare a module with `mod`:
   ```rust
   mod math {
       pub fn add(a: i32, b: i32) -> i32 {
           a + b
       }
   }
   ```

Items inside a module are private by default. Use `pub` to make them public:
   ```rust
   mod math {
       pub fn add(a: i32, b: i32) -> i32 { a + b }
       fn subtract(a: i32, b: i32) -> i32 { a - b } // private
   }
   ```

Reference items in a module with `::`:
   ```rust
   let result = math::add(2, 3);
   ```

The `use` keyword brings paths into scope:
   ```rust
   use std::collections::HashMap;
   ```

Use `pub use` to re-export items, making them accessible from outside the module:
   ```rust
   mod math {
       pub fn add(a: i32, b: i32) -> i32 { a + b }
   }
   pub use math::add;
   ```

Rust programs are compiled by `rustc` or via `cargo`. The `cargo` tool handles dependencies, builds, and more:
   ```bash
   cargo new my_project
   cargo build
   cargo run
   ```

`cargo check` verifies that code compiles without producing a binary â€” useful for quick iteration.
